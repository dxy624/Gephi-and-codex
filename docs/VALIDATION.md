# Alpha 验收

本版本针对 Windows、Gephi 0.11.3、Java 17、Python 3.12。自动检查与验证结论列在相邻的 `validation-summary.json`（发布时生成）。

验收覆盖：

- 无副作用的安装预览、同名配置冲突保护、幂等安装、原有 TOML 配置与注释保留、修改前备份。
- NBM 完整性、Java 17 字节码、独立配置中的两项模块文件提取。
- CSV/XLSX 中文、字符串 ID、零权重、缺失端点、异常权重与重复边规则。
- 干净路径解压、含中文和空格的安装目录、项目 `.venv`、技能与 MCP 的隔离安装。
- 显式启用的真实 Gephi 测试：60 节点、3 社区、240 边、三维布局、节点 12 搜索/聚焦/两阶邻居、分层和视角书签。
- `.gephi` 保存并重新打开后保留场景；25 个 MCP 工具、6000×4000 PNG/PDF 输出。
- 通过 MCP 将中文路径的 GEXF 导入新工作区，保留原图及中文属性、方向、零权重、颜色和 XYZ；错误文件不改变已有场景，重复请求不会重复创建工作区。
- 连接、认证和超时错误，以及旧插件不支持导入的提示；全过程不调用电脑控制。
- 清单限定打包、Markdown 本地链接、排除凭据与个人路径、NBM 与 ZIP 校验值。

原型曾完成 500 节点 / 2,000 边检查，并在 Intel 集成显卡上以 1920×1080 短时离屏旋转 9,000 节点 / 36,000 边得到约 62 FPS。该记录未证明持续交互、布局同时运行或其他显卡上的性能。当前发布验收没有修改原来的 Gephi 工作区或个人 Codex 配置。
