# Alpha 验收

本发行包在 Windows、Gephi 0.11.4、Java 17、Python 3.12 上验收。Gephi 0.11.3 在安装器支持范围内，本次实测使用 0.11.4。自动检查结果见 [验收摘要](validation-summary.json)。

验收覆盖：

- 无副作用的安装预览、同名配置冲突保护、幂等安装、原有 TOML 配置与注释保留、修改前备份。
- NBM 完整性、Java 17 字节码、桌面与独立配置安装。识别到上一公开发行版的桌面插件时备份旧模块，并检查安装预览和重复安装。
- CSV/XLSX 中文、字符串 ID、零权重、缺失端点、异常权重与重复边规则。
- 干净路径解压、含中文和空格的安装目录、项目 `.venv`、技能与 MCP 的隔离安装。
- 原生桌面客户端通过插件接口自动绘制合成网络。独立 Gephi 验收 60 节点、3 社区、240 边、三维布局、节点 12 搜索/聚焦/两阶邻居、分层和视角书签。
- `.gephi` 保存并重新打开后保留场景；32 个 MCP 工具、6000×4000 PNG/PDF 输出。
- 通过 MCP 将中文路径的 GEXF 导入新工作区，保留原图及中文属性、方向、零权重、颜色和 XYZ；错误文件不改变已有场景，重复请求不会重复创建工作区。
- 连接、认证和超时错误，以及旧插件不支持导入的提示；全过程不调用电脑控制。
- 合成 Stata DTA 供应链、城市代码匹配、无法匹配的代码报告、链主社区、地图默认关闭、地图 PNG 和关闭后的相机恢复。
- 普通视图和地图的有向箭头开关、箭头大小、线宽调节。检查 PNG 像素差异，并检查 `.gephi` 工程重新打开后保留设置。
- SVG 由已安装的发行模块在独立测试配置导出。核对可编辑对象、精简图例、重点标签、一阶关系、地图中缺少定位的边和自动取景。
- 核对企业与城市筛选、一/两阶邻居、层显隐、字段配色、SVG 图例与设置保存。用独立实例测试旧版供应链工程兼容性。
- 清单限定打包、Markdown 本地链接、排除凭据与个人路径、NBM 与 ZIP 校验值。

地理模式测试使用合成企业数据和测试几何。用户应配备与城市坐标基准一致的本地底图。全国底图和企业数据不随发行包分发。

真实 Gephi 验收使用临时用户目录和空闲端口 8184。安装检查核对桌面模式的发布默认值 8183。

早期版本曾完成 500 节点 / 2,000 边检查，并记录了 Intel 集成显卡上的短时离屏性能。地图模式的持续交互性能以及其他平台尚待验证。
