# Gephi 三维探索

使用 `gephi3d_*` MCP 工具操作 Gephi 中的同一场景。先读 status 获取当前工作区、布局任务和鼠标选区。“这个节点”“选中的”依据实际选区解释；名字先 search，再用准确 ID 操作。

## 数据与生成

- 没有数据时生成合成示例，默认 60 节点、3 社区、平均度 8、seed 42。模板 `community`、`layered`（有向无环）、`hub`；明确标注非真实观测，不编造真实研究关系。
- generate 新建工作区，使用其返回的新 workspace_id；先做三维布局，再按要求探索。布局异步，查询 status 等待 completed，勿重复提交运行中的任务；每轮最多 1000 次或 30 秒。
- 真实 GEXF 可用 Gephi 菜单导入该实例，再 refresh。CSV/XLSX 的 id/source/target 表先用发行目录 `scripts/tables_to_gexf.py` 转换；方向或重复边含义不明确时询问。
- 三维服务默认是独立实例。Gephi-AI 只有明确连接同一 Gephi 时才可协作；相同 workspace_id 不能证明同一实例，不能跨实例导入、统计或保存。

## 探索语义

- 所有场景操作使用最近状态的 workspace_id。工作区或修订冲突时重读状态；不要对新工作区盲目重试。
- 相机 yaw/pitch 为弧度。相机、标签和样式调整保留位置；仅在生成网络或用户要求时重新布局。
- neighbors 为无向 h 阶邻接；path 为按边数的最短路径，默认尊重有向边。含源节点的高亮数量与“其他邻居数”分开说明。
- highlight/isolation/filter 只影响显示。clear_highlight 保留属性筛选；filter 默认值恢复全部。
- layer 将属性映射到 Z 轴，保持固定节点不动；分层后可继续布局优化层内位置。不要在用户未要求时重设相机。
- 保存或恢复 bookmark；history 保留最近 15 个场景命令，鼠标相机拖动不逐帧进入历史。

## 保存与结果检查

- 优先使用用户明确指定的输出文件夹；未给出位置时可建议用户文档目录中的 Gephi 文件夹。目录不可写时说明失败，不声称保存成功，也不静默换位置。
- 导出前等待布局完成，保存视角书签。PNG 默认 6000×4000，可附 PDF；需要新的绝对文件名，不能覆盖现有文件。PNG 同时写出 `.scene.json`。
- save_project 保存完整 `.gephi` 工程和各工作区场景；save_scene 可输出独立 JSON，当前没有 JSON 导回接口。检查返回路径及保存结果。
- 区分 Alpha 功能和未完成内容：暂缺方向箭头、完整筛选面板、层隐藏控件、任意属性配色和完整图例编辑；不支持时间动画、SVG 或三轴拖拽。

## 连接

请用户从发行目录运行 `Start-Gephi-3D.cmd`，在 Gephi 的“窗口 → 3D Explorer”打开面板。安装脚本默认注册独立实例端口 8184，普通配置中安装 NBM 默认 8183；以实际 MCP 配置为准。

安装需要整个发行包：只有 Skill 不会自动安装 Gephi 插件与 MCP。连接失败时保留当前图，不用生成新图试探连接。token 由本机插件生成，不展示或上传其内容。
